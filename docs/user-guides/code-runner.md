# 在线代码运行

## 页面布局

```text
+----------------+----------------------------------+
| 资源管理器     | 编辑器                           |
|                |                                  |
|                +----------------------------------+
|                | 输出                              |
+----------------+----------------------------------+
```

- 资源管理器与右侧编辑区之间可左右拖动。
- 编辑器与输出区之间可上下拖动。
- 两个分割条都支持实时调整比例。
- 页面高度自动铺满，不保留大面积空白。

## 打开文件

1. 在资源管理器中展开 `/workspace`。
2. 展开目录。
3. 点击文件。
4. 后端读取文本内容后显示到编辑器。
5. 根据扩展名自动切换语言模式。

支持的主要语言：

| 扩展名 | 编辑器 | 执行方式 |
|---|---|---|
| `.py` | Python | `python3` |
| `.js` | JavaScript | `node` |
| `.ts` | TypeScript | `npx tsx` |
| `.java` | Java | `javac` + `java` |
| `.go` | Go | `go run` |
| `.c` | C | `gcc` + 运行 |
| `.cpp` | C++ | `g++` + 运行 |
| `.sh` | Bash | `bash` |
| `.sql` | SQL | `sqlite3 :memory:` |

## 编辑与保存

- 编辑器跟随系统深浅色主题。
- 点击“保存”写回远端路径。
- “复制”复制当前全部源码。
- “读取”重新读取当前路径的文件内容。
- 文件名输入框可用于新建文件的首次保存。

## 编译与运行

- “编译”只执行语言的编译步骤，适用于 Java、C、C++、Go、TypeScript。
- “运行”先保存文件，再执行完整命令。
- 输出面板显示命令、标准输出、标准错误和状态。
- 输出超过 `OPEN_SANDBOX_MAX_OUTPUT_CHARS` 时会显示截断提示。

## 示例

Python 文件 `/workspace/main.py`：

```python
def greet(name: str) -> str:
    return f"你好，{name}!"

print(greet("OpenSandbox"))
```

点击“运行”，实际执行类似：

```bash
python3 '/workspace/main.py'
```

## 运行输出不出现

检查：

1. 是否已选择正在运行的沙盒。
2. 文件是否已成功保存。
3. 输出面板是否被拖到最小高度。
4. 代码是否依赖容器中不存在的解释器或包。
5. 命令输出是否被截断。
