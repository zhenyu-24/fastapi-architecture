# SFTP 文件传输

## 页面结构

SFTP 页面由两个面板组成：

| 面板 | 功能 |
|---|---|
| 远程文件 | 浏览工作区、上传、下载、创建、重命名、删除 |
| 传输记录 | 显示上传和下载状态、进度、大小和远端路径 |

两个面板会铺满页面剩余高度，文件列表和传输记录独立滚动。

## 路径规则

- 默认路径为 `/workspace`。
- 只能在 `/workspace` 及其子目录内操作。
- `..` 越界请求会被后端拒绝。
- 路径输入框支持直接输入绝对路径并按回车。

## 浏览目录

1. 点击目录名称进入。
2. 点击“上级”返回父目录。
3. 点击文件旁的“下载”获取文件。
4. 点击“刷新”重新读取目录。

## 创建目录

1. 输入或进入目标目录。
2. 点击“新建文件夹”。
3. 输入名称。
4. 确认。

示例路径：`/workspace/demo/data`。

## 创建文件

点击“新建文件”，输入文件名和初始内容。新建后可在在线代码运行页面打开并编辑。

## 上传文件

1. 进入目标目录。
2. 点击“上传文件”。
3. 选择本地文件。
4. 等待传输记录显示“完成”。

上限由 `OPEN_SANDBOX_UPLOAD_LIMIT_BYTES` 控制，默认 50 MiB。反向代理也需要配置足够的上传大小。

## 下载文件

点击文件所在行的“下载”。浏览器会通过后端流式读取 OpenSandbox 文件，不直接访问容器。

## 重命名与移动

点击“重命名”，输入目标路径：

```text
/workspace/demo/new-name.txt
```

后端使用 OpenSandbox 文件移动接口完成同目录重命名或跨目录移动。

## 删除

点击“删除”并确认。删除目录时，目录内容会按 OpenSandbox 文件接口行为处理。

## 二进制文件

在线编辑器只打开文本文件。图片、压缩包、可执行文件等应通过下载处理。
