# 使用指南

## 页面入口

沙盒工作台包含以下页面：

| 页面 | 前端路径 | 说明 |
|---|---|---|
| 我的沙盒 | `/online/my-sandbox` | 创建、启动、停止、重启、删除、搜索、筛选和列头排序自己的沙盒 |
| SSH 终端 | `/online/terminal` | 同一沙盒内的持久 Bash 会话 |
| SFTP 文件传输 | `/online/sftp` | 浏览、上传、下载、重命名和删除文件 |
| 在线代码运行 | `/online/code` | 文件管理器、编辑器、可拖拽面板和运行输出 |
| 管理员沙盒实例 | `/admin/sandbox/instances` | 查看并管理所有用户沙盒、创建和同步沙盒、启用/暂停沙盒 API |
| 管理员命令审计 | `/admin/sandbox/audit` | 查询全部用户命令及执行结果 |
| 管理员操作 | 系统管理页或后端管理 API | 所有用户沙盒、命令审计、沙盒 API 启用/暂停 |

“我的沙盒”集中管理沙盒生命周期。三个工作子页面不显示“沙盒管理”按钮，只负责终端、文件和代码操作。管理员功能通过系统管理入口或受保护的管理 API 使用。

管理员“暂停 API”只暂停平台对 OpenSandbox 的调用，不会停止 OpenSandbox Server 进程，也不会删除沙盒、容器或文件；需要真正停止进程时应使用 WSL2、systemd 或 Docker 编排层。

## 权限摘要

| 功能 | 普通用户 | 超级管理员 |
|---|---|---|
| 查看自己的沙盒 | 是 | 是 |
| 创建自己的沙盒 | 是 | 是 |
| 暂停/恢复/重启自己的沙盒 | 是 | 是 |
| 删除自己的沙盒 | 是 | 是 |
| 查看其他用户沙盒 | 否 | 是 |
| 为其他用户创建沙盒 | 否 | 是 |
| 查看命令审计 | 否 | 是 |
| 启用/暂停沙盒 API（不停止进程） | 否 | 是 |

## 用户流程

1. 登录系统。
2. 进入“沙盒工作台 → 我的沙盒”。
3. 首次使用时创建沙盒，等待状态变为“运行中”。
4. 从沙盒行选择“终端”“文件”或“代码”进入对应工作页面。
5. 使用结束后可在“我的沙盒”中停止或删除沙盒；空闲超时后系统也会自动停止。
