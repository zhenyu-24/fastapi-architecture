# 沙盒工作台

沙盒工作台由“我的沙盒”和三个工作子页面组成。沙盒的创建、启动、停止、重启、删除、搜索、筛选和排序集中在“我的沙盒”页面；终端、SFTP 和代码运行页面继续提供当前沙盒选择器和刷新能力。

## 1. 创建沙盒

1. 进入“沙盒工作台 → 我的沙盒”。
2. 点击“新建沙盒”。
3. 输入名称，例如 `python-lab`。
4. 点击“创建”。
5. 等待状态从“创建中”变为“运行中”。

每个用户默认最多保留 2 个沙盒，由 `OPEN_SANDBOX_MAX_SANDBOXES_PER_USER` 控制。达到上限后，需要先删除不再使用的沙盒。

## 2. 打开工作页面

在“我的沙盒”的沙盒行中点击：

- “终端”：进入 SSH 终端。
- “文件”：进入 SFTP 文件传输。
- “代码”：进入在线代码运行。

“我的沙盒”操作列还提供“重命名”，可修改沙盒显示名称；名称会同步到 OpenSandbox 的 `fba_name` 元数据。

只有运行中的沙盒可以直接打开工作页面。已停止的沙盒需要先点击“启动”。

## 3. 选择沙盒

三个工作子页面的顶部工具栏会显示当前账号可用的沙盒。下拉框显示名称和状态；切换沙盒会清空当前页面的会话、文件列表或编辑器状态。通过 URL 中的 `sandbox_id` 也可以打开指定沙盒。

## 4. 停止、启动与平台 API 开关

“停止”对应 OpenSandbox 暂停：

- 容器仍然存在。
- `/workspace` 文件保留。
- 进程状态保留。
- 再次启动后继续使用。

可以在“我的沙盒”中执行启动和停止；三个工作子页面只保留沙盒选择和刷新，不再显示生命周期按钮。空闲时间超过 `OPEN_SANDBOX_IDLE_TIMEOUT_SECONDS` 后，后端会自动暂停。

### 平台 API 被暂停

如果管理员在“系统管理 → 沙盒管理 → 沙盒实例”点击“暂停 API”，所有用户会看到“沙盒 API 已被管理员暂停，OpenSandbox 进程仍在运行”。此时：

- 平台不会调用 OpenSandbox 的创建、命令、文件等接口；
- 已有沙盒、容器和 `/workspace` 文件不会被删除；
- 终端、SFTP、代码运行和沙盒生命周期操作不可用；
- 需要联系管理员点击“启用 API”恢复。

这与“停止沙盒”不同：停止沙盒只暂停自己的容器，平台 API 开关影响所有用户。

### 重启

运行中的沙盒可以点击“重启”。当前 OpenSandbox SDK 没有独立 restart 接口，插件通过暂停后立即恢复实现；工作区文件和暂停前保留的进程状态不会被删除。

## 5. 查询、筛选与排序

“我的沙盒”工具栏支持：

- 按沙盒名称、ID、镜像或状态关键词搜索。
- 按运行中、已停止、创建中、失败筛选状态。
- 点击“沙盒名称”“沙盒 ID”“状态”“最后活动”列头上的上下箭头排序，每次点击在升序和降序之间切换。
- 点击“重置”恢复默认搜索、筛选和“最后活动（新→旧）”列排序。
- 结果区域显示“匹配数量 / 沙盒总数”。

## 6. 删除沙盒

在“我的沙盒”中点击“删除”，确认后永久删除沙盒。删除会丢失未导出的文件和运行状态，且不可恢复。仅删除自己的沙盒；管理员删除其他用户沙盒需使用管理员接口或系统管理页面。

## 7. 四个页面

| 页面 | 适用操作 |
|---|---|
| 我的沙盒 | 创建、启动、停止、重启、删除、搜索、筛选、列头排序和查看配额 |
| SSH 终端 | Shell 命令、目录切换、环境变量、运行脚本 |
| SFTP 文件传输 | 文件上传、下载、目录浏览、创建、重命名、删除 |
| 在线代码运行 | 文件树、代码编辑、保存、编译、运行与查看输出 |

## 8. 工作目录

默认工作目录是 `/workspace`。文件管理器限制在 `/workspace` 内，终端会话可以切换到其他目录，但文件传输接口仍只允许工作区路径。

## 9. 命令审计

终端、代码运行和必要的文件命令会写入 `sys_opensandbox_command`。审计内容包括：

- 用户与沙盒
- 命令和来源
- 工作目录
- 标准输出和标准错误
- 退出码
- 执行耗时
- 是否截断

普通用户不能读取审计接口，只有管理员可以查询。
