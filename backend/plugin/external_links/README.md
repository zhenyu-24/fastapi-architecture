# 外部页面

管理外部网站的多级分类，支持内嵌、新窗口打开、多级菜单和分类按钮导航

## 插件类型

- 扩展级插件，扩展 `admin`

## 配置说明

- 无额外环境变量或第三方依赖，使用项目默认数据库
- 配置存储于 `sys_external_link`，启动时由 ORM 自动建表，初始化 SQL 不预置链接
- 配置接口位于 `/api/v1/sys/external-links`，`/manage` 查询全部配置；写入及管理查询仅允许超级管理员
- 普通登录用户仅能查询已启用的配置，停用父分类会隐藏全部后代
- ID 以字符串返回，兼容自增和雪花主键；父分类必须存在，禁止循环分类和直接删除非空分类
- 图标可从内置列表选择，也可上传 PNG/JPG/GIF/WebP/SVG 图片（不超过 5MB）；图片上传复用 `files` 文件上传插件，需启用该插件
- 上传图标保存为 `/static/upload/` 相对路径，前端按 API 服务地址加载，无需修改现有图标字段
- 保存图标时在同一事务中登记文件引用，替换或删除时解除旧引用；取消编辑留下的临时图标超过保护期后自动回收

## 使用方式

1. 将插件放入后端插件目录并重启后端，启动时自动创建数据表
2. 超级管理员进入前端“系统管理 / 外部链接”添加分类与链接
3. 分类可选择多级菜单或分类按钮；链接可选择内嵌或新窗口打开
4. 登录用户从“外部页面”访问启用的分类和链接；停用父分类会同时隐藏其子项
5. 目标网站须允许 iframe 嵌入，HTTPS 系统内嵌应使用 HTTPS 地址；拒绝嵌入的网站可改用新窗口打开

## 卸载说明

- 在插件管理中停用或卸载插件，同时清理相关前端入口
- 保留所需配置备份后再执行插件数据清理
